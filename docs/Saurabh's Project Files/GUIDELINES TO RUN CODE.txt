
# 📄 Project Execution Guidelines

## ML-Based DDoS Detection in 5G Networks

---

## 📌 1. Project Overview

This project implements a **machine learning-based anomaly detection system** for detecting **DDoS attacks in 5G/B5G networks** using the **NCSRD-DS-5GDDoS dataset**.

The system includes:

* Baseline ML model (XGBoost)
* Correlation-based anomaly detection
* Adaptive thresholding
* SHAP-based drift detection

📊 Final performance improves from:

* **Baseline F1 Score:** 0.9573
* **Best Model F1 Score:** 0.9730 

---
